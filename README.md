# solo-8800002

一个基于 Vite + Vue 3 的纯前端小众业务示例项目，主题是古籍虫蛀修复批次管理。

## 开发

```bash
npm install
npm run dev
```

`vite.config.js` 已显式配置 `server.open = false`，启动开发服务时不会自动打开浏览器。

## 构建

```bash
npm run build
```

## 任务风险排序

- 任务清单页可组合「风险等级 / 等待时长 / 文献完整度」三类排序因子生成风险顺序，并支持风险等级筛选与关键词搜索。
- 综合风险分 = 风险等级基础分（高 100 / 中 60 / 低 30）+ 等待时长（每天 +1.5）+ 完整度缺口（每缺 1% +0.2），因子可单独开关。
- 同分时依次比较等待时长、文献完整度（缺失一律按 0% 处理），仍相同按任务编号升序，保证顺序稳定。
- 查看条件保存在 sessionStorage，本次会话内有效；修复总览与任务清单共用同一 composable，两处风险顺序与统计始终一致。
